open skill · xxd-draw-001

一句话，
画成一幅会动的画

把一句描述、一张照片，或照片加几句修改交给 Agent。它先读懂画面里该有什么，再用干净的颜色和柔软的笔触，一笔一笔画出来。每幅作品都是一个离线就能打开的 HTML。

    how to use

    怎么用

    装进 Claude Code 或 Codex 的 skills 目录，然后像平时说话一样下命题。

    1. 安装

      git clone https://github.com/nevertoday/xiaoxiaodong.git
cp -r xiaoxiaodong/skills/xxd-draw-001 ~/.claude/skills/

      Codex 复制到 ~/.codex/skills/。需要 Python 3 + Pillow；自检步骤用 Node.js + Playwright。

    2. 文字命题

      $xxd-draw-001 画一幅：冬天结冰的湖面上，两只丹顶鹤在跳舞。

      诗句、场景、抽象的情绪都可以。命题里的每个意象都会画出来，漏了就不交付。

    3. 照片，或照片 + 修改

      $xxd-draw-001 把这张照片画成作品，天空换成黄昏。

      附上照片即可。默认画成正方形，颜色取自照片本身；想要竖幅、横幅直接说。

    4. 批量

      python3 ~/.claude/skills/xxd-draw-001/scripts/batch_run.py 命题.txt --out 输出目录

      一题一个独立 worker，互相看不到别的命题，跑完自动查重，构图雷同的会重画。

    画什么
    由命题决定。没有预设色板和现成主体，Agent 按每样东西实际的样子去描述它。
    怎么画
    由引擎决定。湿边色带、有机形、同色明暗、成片的小笔触，分阶段展开。
    自检
    漏画意象拒绝生成；检查彩度、脏灰、明度、笔触密度和作画节奏。

    画风灵感来自 Sasha 的 Painting Loaders。内嵌 p5.js（LGPL-2.1）与 p5.brush（MIT）。照片输入的原图来自 Unsplash。
